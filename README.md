# GPX · KML · AZALERA — V2.11.23e WEB

Versión final para GitHub Pages.

## Incluye

- Visor responsive para móvil, tablet y ordenador.
- GPX/KML.
- B5M / IGN / PNOA / EU Huts.
- Waypoints con iconos y nombres.
- PDF MAPA TXOSTENA.
- Exportación SHP del polígono/superficie del visor.
- SHP en ETRS89 / UTM 30N (EPSG:25830).
- Atributos de superficie en hectáreas y perímetro en metros.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube a la raíz:
   - index.html
   - favicon.svg
   - manifest.webmanifest
   - 404.html
3. Ve a Settings > Pages.
4. En Build and deployment:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /(root)
5. Guarda.

La web quedará disponible en una URL similar a:
https://TU-USUARIO.github.io/NOMBRE-REPOSITORIO/

## Nota
La aplicación necesita conexión a Internet para cargar librerías y cartografías externas.
